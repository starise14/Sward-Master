## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | **Sward Master** |
| 장르 | VR / Action / Hunting |
| 개발 엔진 | Unreal Engine 5.4.4 |
| 플랫폼 | PC |
| 플레이 방식 | Single Player |
| 시점 | First Person |
| 예상 플레이 시간 | 5~10분 |

### 한 줄 소개
> VR세상에서 투기장의 거대한 몬스터의 공격을 피하며 검으로 몬스터를 죽이는 보스 러쉬 게임

---

## 2. 게임 컨셉

중세 기사인 당신은 투기장에 나타난 거대한 용을 처치해야 한다.

용은 당신을 계속 공격하며 당신은 용의 공격을 피하며 계속 공격을 해야 한다.

최종적으로 투기장에 나타난 용을 죽이면 게임을 클리어한다.

### 핵심 키워드

- **Encounter** : 투기장에 배회하는 용과의 조우
- **Combat** : 검을 이용한 VR 전투
- **Victory** : 용을 쓰러트려 승리

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.

1. 투기장을 배회하는 용과 조우한다.
2. 용이 플레이어를 발견하면 조우 애니메이션이 발생한다.
3. 용의 공격을 피하면서 용을 공격한다.
4. 용을 처치하면 게임 클리어

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
투기장 입장
  ↓
적 발견
  ↓
공격 및 회피
  ↓
용을 처치
  ↓
승리
```

플레이어는 용을 조우한 뒤 게임이 종료될 때까지 **회피 → 공격**의 과정을 반복한다.

| 입력 | 기능 |

| 오른쪽 컨트롤러 조이스틱 | 캐릭터 이동 |

---

## 6. 플레이어 기능

### 6.1 이동

플레이어는 컨트롤러의 조이스틱을 이용하여 몬스터의 공격을 회피할 수 있다.

주요 기능:

- 검의 평평한 면을 앞으로 들어 공격을 방어
- 검을 휘둘러 접촉 시간에 따른 공격 판정
